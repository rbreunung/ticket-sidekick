Point Ticket Sidekick at your Bitbucket Data Center instance so `@bitbucket` knows where to send requests.

[Open Bitbucket base URL setting](command:workbench.action.openSettings?%22ticketSidekick.bitbucket.baseUrl%22)

Paste your Bitbucket Data Center base URL (e.g. `https://bitbucket.mycompany.com`) into **Ticket Sidekick › Bitbucket: Base Url**. On Bitbucket Cloud, skip this — Cloud always talks to the fixed `api.bitbucket.org` host, so this step completes together with the credentials step below.
