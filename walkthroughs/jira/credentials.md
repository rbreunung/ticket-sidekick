Ticket Sidekick needs Jira credentials to read and write tickets on your behalf. Credentials are stored in VS Code's encrypted Secret Storage — never in `settings.json`.

[Set Data Center Personal Access Token](command:ticket-sidekick.setDataCenterToken)

[Configure Cloud Credentials](command:ticket-sidekick.configureCloud)

Use the first command if you're on Jira Data Center (a Personal Access Token). Use the second if you're on Jira Cloud (your Atlassian account email plus an API token from id.atlassian.com). This step completes automatically once credentials are saved.
