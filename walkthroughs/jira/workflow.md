See the ticket types and status-transition workflow Ticket Sidekick discovers by sampling real tickets in your project — the same data multi-hop ticket transitions rely on later.

[Ask @jira to discover the workflow](command:workbench.action.chat.open?%5B%7B%22query%22%3A%22%40jira%20discover%20workflow%20%22%7D%5D)

In the chat box that opens, finish the prompt with your project key and an issue type, e.g. `@jira discover workflow PROJ Bug`. This step completes once discovery actually finishes and the workflow graph is cached.
